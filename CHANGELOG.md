## [0.1.0] - 2026-09-19

### Added

- Antigravity `PreToolUse` plugin powered by TypeSafe Jev.
- Deterministic holds for destructive commands and sensitive paths.
- Fail-closed handling for missing credentials, timeouts, transport errors, and invalid responses.
- Configurable probability, confidence, model, endpoint, and timeout settings.
- Secret redaction and bounded recent user-intent context.
- A 24-case safety benchmark with deterministic and live modes.
- Unit tests, Docker/headless E2E validation, security guidance, and public documentation.
- Sanitized live Jev trace capture plus an accessible HyperFrames HTML composition and animated README GIF.
- Real Antigravity denial evidence and terminal screenshot for a blocked `git push` call.
- Separate 0.80 safe-probability tier for strictly recognized read-only inspection calls; mutating calls retain the 0.90 threshold.
